= Astra API (ACS) Anmeldeinformationsendpunkte
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
Objekte, die sensible Informationen enthalten, können in Astra Control sicher gespeichert und gemanagt werden.

Die Credential API bietet Zugriff auf das sichere Persistieren von Objekten, die sensible Informationen enthalten.
